## Лабораторная работа №2
### Класс итератор с гибкой настройкой и удобными применением

```python
class CountDown:
    def __init__(self, start):
        self.count = start + 1
    def __iter__(self):
        return self
    def __next__(self):
        self.count -= 1
        if self.count < 0:
            raise StopIteration
        return self.count
if __name__ == '__main__':
    counter = CountDown(5)
    for i in counter:
        print(i)
```
### Результат.
![Меню]()

## Выводы
Код создает класс CountDown, который реализует итератор для обратного отсчета.
__init__ инициализирует значение.
__iter__ возвращает объект как итератор.
__next__ уменьшает значение на 1 и возвращает его, пока не достигнет -1, после чего вызывает StopIteration.

## Лабораторная работа №4
### Выражения генераторы

```python
b = (1 ** 2 for i in range(1, 5))
print(b)
print('first')
for i in b:
    print(i)
print('second')
for i in b:
    print(i)
```
### Результат.
![Меню]()

## Выводы
В данном коде создается генераторное выражение, которое вычисляет квадрат числа 1 для каждого значения в диапазоне от 1 до 4. При этом сам генератор не создает список значений, а генерирует их по мере необходимости. 
Первый print выводит информацию о генераторе, а не его значения. Затем, в первом цикле for, происходит итерация по генератору, и выводится значение (все итерации вернут 1, так как квадрат 1 всегда равен 1). После этого второй цикл for пытается снова пройтись по тому же генератору, но так как генератор уже исчерпан, он не выведет ничего. Таким образом, вторая итерация не даст никаких результатов.

## Лабораторная работа №5
### Такой же счетчик, как и в первом задании, только это генератор и использует yield

```python
def countdown(count):
    while count >= 0:
        yield count
        count -= 1
if __name__ == '__main__':
    counter = countdown(5)
    for i in counter:
        print(i)
```
### Результат.
![Меню]()

## Выводы
Данный код определяет генератор countdown, который принимает целое число count и поочередно возвращает значения от этого числа до нуля, уменьшая его на единицу после каждого вызова. 
В блоке, который проверяет, является ли текущий модуль основным (if __name__ == '__main__':), создается экземпляр генератора с начальным значением 5. Затем в цикле for происходит итерация по этому генератору, и каждое значение (от 5 до 0) выводится на экран. 

## Самостоятельная работа №1
### Вас никак не могут оставить числа Фибоначчи, очень уж они вас заинтересовали. Изучив новые возможности Python вы решили реализовать программу, которая считает числа Фибоначчи при помощи итераторов. Расчет начинается с чисел 1 и 1. Создайте функцию fib(n), генерирующую n чисел Фибоначчи с минимальными затратами ресурсов. Для реализации этой функции потребуется обратиться к инструкции yield (Она не сохраняет в оперативной памяти огромную последовательность, а дает возможность “доставать” промежуточные результаты по одному). Результатом решения задачи будет листинг кода и вывод в консоль с числом Фибоначчи от 200.

```python
def fib(n):
    a, b = 1, 1
    for _ in range(n):
        yield a
        a, b = b, a + b
fibonacci_numbers = list(fib(200))
print(fibonacci_numbers[199]) 
```
### Результат.
![Меню]()

## Выводы
Этот код определяет генератор fib, который генерирует числа Фибоначчи. Он принимает целое число n и возвращает первые n чисел последовательности Фибоначчи. Внутри функции используются две переменные a и b, которые поочередно обновляются, чтобы вычислить следующее число в последовательности. 
Затем создается список fibonacci_numbers, который содержит 200 первых чисел Фибоначчи, и выводится 200-е число (индекс 199) из этого списка.

## Самостоятельная работа №2
### К коду предыдущей задачи добавьте запоминание каждого числа Фибоначчи в файл “fib.txt”, при этом каждое число должно находиться на отдельной строчке. Результатом выполнения задачи будет листинг кода и скриншот получившегося файла

```python
def fib(n):
    a, b = 1, 1
    with open("fib.txt", "w") as f:
        for _ in range(n):
            f.write(f"{a}\n")
            yield a
            a, b = b, a + b
fibonacci_numbers = list(fib(200))
print(fibonacci_numbers[199])
```

## Выводы
Этот код определяет генератор для вычисления чисел Фибоначчи. Функция fib принимает число n и записывает первые n чисел Фибоначчи в файл "fib.txt". При каждом вызове генератора она возвращает текущее число Фибоначчи, обновляя значения для следующего числа. В конце создается список из 200 чисел Фибоначчи, и выводится 200-е число из этого списка.
