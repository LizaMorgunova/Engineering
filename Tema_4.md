def calculate_area(a, b, c):

## Выводы
Создана функция, которая принимает длины трех сторон треугольника. Вычисляем полупериметр и затем площадь по формуле Герона. Возвращаем вычисленную площадь. Во втором файле производим взаимодействие с пользователем и запрашиваем его длины сторон. Вызываем функцию, выводим результат с помощью "точки входа".

## Общие выводы по теме
Написание этих программ иллюстрирует важные аспекты разработки программного обеспечения: структурирование кода, взаимодействие с пользователем. Программы позволяют применять математические и иные формулы. Они просты в использовании. Это полезный инструмент для изучения основ программирования и работы с функциями, а также для практического применения математических знаний.
